# 独立管理页与认证

管理页提供两个入口，连接同一个 Runtime、主会话与数据库：

- `/amphoreus/`：嵌入 DSH 侧栏，复用宿主的 owner 认证。
- `/console/`：独立管理入口，使用翁法罗斯自身认证。

配置实际访问地址的 `api.allowedHosts`，例如 `localhost:2333` 或 `bot.example.com:2333`。Host / Origin 校验必须与反向代理和外部地址一致；不要使用任意来源通配符。真实令牌、账户与证书写在 Git 外的部署配置中。

## 账户与权限

独立入口支持账户密码、TOTP 与恢复流程；已有管理令牌可用于初始化和受控 API 访问。浏览器不在 URL 中携带令牌。管理员可以调整角色、渠道、会话、记忆和后台任务，普通聊天账户只能访问自己获准的会话范围。

写请求需要 `x-amphoreus-request: 1`，并遵循同源检查。登录失败会限流。公开接口不返回模型凭证、原始配置或私人 Persona；关于页只展示程序元数据和第三方许可。

## HTTPS 与部署

将 DSH Web 或翁法罗斯管理服务绑定到所需的内部接口，再由受控反向代理提供 HTTPS。证书及私钥保存在独立部署目录，切勿加入仓库或 npm 包。外部 HTTPS 生效后，按实际配置启用 `api.secureCookies`。

更新服务前检查是否有正在运行的主会话或后台任务，保留数据库、原生日志、账户配置和工作目录。端口映射、TLS 与公开可达性应在部署端分别验证；本源码不携带个人域名、证书或 DNS 配置。
