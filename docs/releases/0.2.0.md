# 翁法罗斯 0.2.0

本版包含记忆增强和 0.1.0 发布后的兼容性、稳定性修复。原文、原生 Session 与现有私人配置保留。

## 更新内容

- Heart 不再自动注入跨渠道近期快照或人物印象；Hybrid 按实际观察状态补足同来源遗漏区间，默认附加预算 1000 Token。
- 支持结构化记忆候选、证据校验、巩固批次提交、断点恢复及独立历史回填；正式 Self、日记与采纳仍由 Main 确认。
- 中文 FTS5 bigram 检索、事实有效期与已确认人物引用；新增统计、来源展示和记忆不变量告警。
- Main 普通回复、审阅与协作默认不限运行时间；压缩触发、预留和保留量跟随 DSH 原生限额，没有固定 32k 预唤醒压缩。
- 修复媒体工具参数的纯 JSON 兼容性、缺少基础版本的旧 Self 草稿首次确认、历史 Session 游标保留和聊天刷新窗口增长问题。

## 升级须知

升级前停止角色 Runtime，保存 SQLite 一致备份、原生 Session、私有配置与工作区。首次启动将记忆 Schema 1 升级到 2，并建立可重建索引；原文不因索引升级删除，reasoning 继续遵守原有 TTL。降级到 Schema 1 程序需要恢复一致备份，不能只替换旧包或修改版本号；避免覆盖升级后新发生的经历。

新的 `memory.dreaming.consolidation` 默认关闭，原有夜间潜意识回顾继续工作。原生压缩真实链路及 150K 集成验收本轮暂缓；测试与基准结果不是实际模型回答质量、Windows 实机或长期线上运行证明。详细协议、性能和验证边界见[记忆增强实施记录](../memory-enhancement.md)。
