# 关于页与分级开关

总开关、渠道开关、会话开关依次约束处理权限；子开关不能绕过关闭的父级。开关保存在角色自己的 SQLite 数据库，重启和私密备份恢复后继续生效。仅管理员可以修改；管理接口及历史查看不受这些开关限制。

- 关闭总开关：不启动新的 Main、后台任务或回顾；中止当前推理及后台执行，不再对外发送。潜意识和话题分支保留 Session，开启后可以继续；已执行工具的技术助手保留中断记录，不自动重做可能产生副作用的操作。尚未开始的任务在开关开启后继续排队。
- 关闭渠道或某个会话：停止该来源的推理、执行和对外发言，不影响其他渠道。QQ 会话开关直接使用现有接收设置，关于页和群聊参与页修改的是同一份设置；恢复接收继承只移除接收覆盖，不清除消抖设置。
- 关闭期间的原始消息保留在网关及全局记忆，不自动送模型，不在重新开启后补发。已经进入请求或已经发出的内容无法撤回。此前失败消息的恢复和邮件告警会暂缓到发送开关允许后。

管理员 `GET/POST /api/control`。仅传 `enabled` 控制总开关；带 `platform` 控制渠道；再带 `account_id/conversation_id` 控制会话。`reset:true` 恢复会话继承，不能同时传 `enabled`。QQ 必须匹配实际接收账号，网页会话必须匹配其账号命名空间。B站尚未接入，不能通过开关提前启用。

关于页展示已知群聊／私聊、QQ 提供的已加入群以及手动指定的会话。关闭开关不等于踢群、删好友或删除聊天记录。全角色暂停使用总开关，管理服务可以保持运行以便再次开启。上线管理服务前先持久化总开关关闭，启动管理服务不代表恢复角色推理；验收使用离线模型替身，不为验证消耗生产模型 Token。
